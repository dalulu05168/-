# 2.1.1：透明 Logo 与 1 毫米模块间距

- Logo 资源仍是原有 RGBA 文件（Alpha 范围 0–255），未重绘、重新着色或替换。
- 删除登录页和侧栏 Logo 容器的底色、背景图、边框、圆角、阴影和内边距，直接显示透明图片。
- 页面外侧留白、相邻模块卡片的行列间距统一采用 CSS `1mm`，并去掉叠加的外边距；文字区域保留内部留白。
- 1440px 和 390px 视口实测边到边间距为 3.765625 CSS px（布局取整后），计算样式为 3.77953px；均无页面横向溢出。
- [实际首页截图](previews/dashboard.png) · [实际登录页截图](previews/login.png)，均为模拟数据预览。

屏幕中的毫米使用浏览器 CSS 单位，不对显示器物理尺寸、缩放或像素密度作额外校准。
