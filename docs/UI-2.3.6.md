# 2.3.6 — unified surfaces, navigation docking and motion

The shell and navigation share one vertically matched deep-blue gradient. Panel, table/header, control and monitor surfaces use closely related blues to reduce abrupt contrast while retaining readable silver text, gold accents and the project ring colors. Original logo assets and backend settings are unchanged.

All page action slots, global search and user controls dock below the navigation menu on desktop. Controls retain their DOM nodes and handlers. Smaller layouts place them below the top bar. A fixed, keyboard-accessible navigation toggle hides/reveals navigation, updates aria-expanded, reclaims content width, persists the device preference and moves controls into a reachable top toolbar while hidden. It triggers chart/layout resizing. The toggle remains reachable while navigation is hidden.

The project monitor now uses evenly spaced data columns with an aligned identity area and clock. Major cards/panels across all pages share a subtle lift, gradient shift, border light and shadow on hover; focus remains visible and reduced-motion preferences disable movement. Existing ring interactions remain.

Browser checks cover both roles and all page navigation; additional checks cover all admin views at 1440/1060/768/390 widths, action docking, hide/expand, reload persistence, no overflow and no page errors. Project/customer PNG export checks retain ring color, layout and complete export coverage. No public preview images were uploaded.
