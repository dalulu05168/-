# 桌面界面 2.1.0

排版参考 Canva 设计 DAHYZLSEJrY：https://www.canva.com/design/DAHYZLSEJrY/view 。实际程序使用现有数据字段，未采用 Canva 演示稿中的虚构资产规模、项目数或增长率。

已修改程序页面，而非仅生成设计图：

- 216px 固定侧栏、统一线性图标、紧凑品牌区和顶部搜索栏。
- 管理员与二级账户统一仪表盘结构，数据范围继续由现有权限控制。
- 四项可点击指标、7/30/90 日趋势、跟进日程、近期交易表格、按币种独立的成本基准及项目入口。
- 登录页及其他模块的表格、卡片、表单、按钮使用统一深蓝视觉样式。
- 窄屏底部导航和表格内部滚动。

未修改 Logo、应用图标文件、生产数据库或后端业务代码。原始 Logo 附件尚不能读取，程序继续使用既有资源文件，本版不声称已恢复原始附件。

验证包括 20 项测试（含日期边界与大数据趋势回归检查）、两角色和两种宽度的模块浏览检查、界面截图检查，以及 Windows 安装器构建后的安装、登录页启动与卸载检查。真实账号完整联网流程未因本次 UI 调整重新验收。
