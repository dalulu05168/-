Ellery Westcott CRM 2.0.1 · Windows 10/11 x64

下载安装 `Ellery-Westcott-CRM-Setup-2.0.1.exe`，使用现有授权账号登录；无需另装 Node.js。联网访问现有 CRM 数据服务。

- 透明品牌 Logo、深蓝渐变布局，保留客户、持仓、交易、行情、项目份额、报表和导出入口。
- 仅管理员与二级账户；旧一级账户登录和自有数据沿用现有后端的迁移结果。
- 修复客户新增时的管理员归属字段，登录 SDK 随应用打包，网络失败时仍显示登录入口。
- Windows 构建流程执行测试、构建、静默安装、启动登录界面和卸载检查，通过后上传安装包。

本版未修改原网站页面。桌面版和网站共用现有后端，业务数据会同步，不属于独立数据库系统。
安装器未配置代码签名证书。自动化安装运行检查不等同于人工完成全部联网业务验收；当前开发环境无法直连登录服务，因此不声称已通过提供账号的完整登录业务测试。
