# 2.3.4 — optional interface trial

The application menu adds “新界面试览（模拟数据）”. This opens a separate sandboxed window with an in-memory session, local simulated fixtures and all remote requests blocked. Normal login, database configuration and default page appearance remain unchanged. No logo asset was replaced.

The trial shows a larger original logo with perspective and layered lighting, staggered login entrance and slow ambient light. The login button enters the simulator without requiring credentials. Market cards gain an elevated hover state, headings gain icon spacing, metric icons sit beside their labels and the price line uses gold. Project controls move to a toolbar below a dedicated animated project monitor. Three rings use 136px desktop / 120px mobile dimensions and retain matching gold, green and blue percentages and amounts. Hover and keyboard focus lift each ring 7px, enlarge it 4.5% and add its own colored glow; pointer exit restores it. Reduced-motion preferences disable movement.

Only `demo=1&designPreview=1` enables the trial. Other pages and the default desktop view keep their previous appearance. Simulated source fixtures are explicitly labeled test data. Images have not been uploaded publicly.
