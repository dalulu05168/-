# ELLERY WESTCOTT CAPITAL MARKETS — 三语言 UI 实施基线
本分支从 main 的 a319195adbd3e98cfe19c24cee6d01899d083ee9 派生，独立进行 UI 升级；不要把设计稿中的人物、金额、资产数据写入现有 CRM。
## 原有功能不可破坏
Supabase 身份验证、admin/level1/level2、RLS、客户/员工管理、交易记录、持仓计算、行情、报表、项目份额预留、客户预留记录、导出都保持现状。
## 视觉
桌面采用 16:9 内容构图，深蓝与白/冷灰渐变，左侧导航、顶栏和多级卡片；狭窄设备改为可访问的响应式布局。样式统一覆盖历史主题但不修改数据库。
## 语言
中文 zh、English en、Română ro。现有 ui-features.js 的 getLang()/tr()/translateUI() 保留和扩展。所有用户可见的菜单、字段、按钮、状态、弹窗、通知应按三语字典翻译；所有服务端字段及用户姓名不翻译。
## Logo
必须使用用户在对话提供的蓝色建筑标志与公司名的原始 PNG；旧 Brantone Veylor 只保留历史测试与可回滚资源，新界面不再显示。
## 验收
1. `npm test`; 2. `node --check app.js` 和新增 JS；3. 1600×900 / 1920×1080 / 1280×720 / 390×844 浏览器截图比对设计稿；4. 登录和导航、交易/预留业务动作、权限、错误提示、三语言切换功能回归；5. 独立预览验收后才合入 main。
